# Darkroom

[English](README.md) · **한국어**

Darkroom은 Windows용 RAW 사진 관리·비파괴 현상 프로그램으로, 널리 쓰이는 상용 사진 보정 프로그램을 대신해 쓸 수 있는
독립 프로그램입니다. 설치 없이 실행 파일 하나로 동작하고, 다른 소프트웨어가 필요하지 않습니다.

## 주요 기능

**라이브러리**
- 별점·색상 라벨·플래그·키워드·제목·캡션이 있는 카탈로그
- 컬렉션, 스마트 컬렉션, 빠른 컬렉션, 스택, 가상 사본
- 그리드·루페·비교·서베이 보기, 필터·정렬·검색
- 인물: 얼굴을 찾아 같은 사람의 사진끼리 묶음 (이 PC 안에서 처리)
- 가져오기(그 자리에 추가·복사·이동), 이름 일괄 변경, 여러 카탈로그와 자동 백업

**현상**
- 화이트 밸런스, 노출, 대비, 하이라이트, 섀도, 화이트, 블랙, 텍스처, 명료도, 디헤이즈, 바이브런스, 채도
- 톤 커브(파라메트릭·포인트, 채널별), HSL·흑백 혼합, 포인트 컬러, 컬러 그레이딩, 보정(캘리브레이션)
- 샤프닝, 노이즈 감소, 렌즈 교정, 변형(자동 원근), 자르기·수평 맞추기, 비네팅·그레인
- 로컬 마스크: 브러시, 선형, 방사형, 색상 범위, 휘도 범위, AI 마스크(피사체·배경·하늘·사람)
- 스팟 지우기, 적목 보정, 얼굴·번호판 가리기
- 히스토리, 스냅샷, 프리셋, 설정 복사·붙여넣기·동기화, 이전/이후·분할 보기, 참조 보기, 소프트 교정

**색과 렌즈**
- DNG 명세의 색 모델 위에 Darkroom 자체 카메라 프로파일(약 120기종)과 룩, 처음 보는 기종용 일반 프로파일
- 공개 렌즈 자료 [lensfun](https://lensfun.github.io)(내장)과 카메라가 RAW 파일에 적어 둔 렌즈 보정 자료로 렌즈 교정

**합치기와 AI**
- HDR 병합, 파노라마 병합
- AI 향상(노이즈 감소·해상도), AI 마스크, AI 지우기 — 모든 처리는 이 PC 안에서

**내보내기**
- JPEG·TIFF·PNG로 내보내기, sRGB·Adobe RGB(1998) 호환·Display P3, 크기 조절·출력 선명도·워터마크(글자·이미지)·메타데이터 설정,
  내보내기 프리셋
- 인쇄 레이아웃(PDF), 슬라이드쇼

**다른 사진 보정 프로그램에서 옮겨 오기**
- 널리 쓰이는 사진 보정 프로그램의 카탈로그(`.lrcat` — 현상 설정·히스토리·컬렉션 포함), 현상 프리셋, XMP 사이드카 가져오기
- 다른 사진 보정 프로그램이 읽을 수 있는 XMP 사이드카 쓰기

## 설치

[Releases](https://github.com/OrionNestBot/Darkroom/releases)에서 `Darkroom.exe`를 받아 실행합니다 (Windows 10·11, 64비트).

- 카탈로그와 캐시는 `%LOCALAPPDATA%\Darkroom\`에 저장되고, 원본 사진은 수정하지 않습니다.
- AI 기능은 처음 쓸 때 필요한 파일을 받습니다. 모든 파일은 SHA-256으로 확인하고, 처리는 모두 이 PC 안에서 합니다.
- HEIC는 Microsoft Store의 "HEIF 이미지 확장"이 있어야 열립니다.

### 프로그램을 업데이트하지 않고 새 카메라·렌즈 쓰기

데이터 폴더(`%LOCALAPPDATA%\Darkroom\` — 환경설정에서 열 수 있음)에 파일을 넣으면 다음에 실행할 때부터 씁니다.

| 폴더 | 넣는 것 |
|---|---|
| `cameras` | [rawler](https://github.com/dnglab/dnglab) 카메라 정의(`.toml`). 목록에 없는 기종은 넣지 않아도 같은 회사의 가장 비슷한 기종 설정으로 열고 알려 줍니다. |
| `profiles` | DCP 카메라 프로파일 (DNG 명세의 공개 형식) |
| `lensfun` | [lensfun](https://lensfun.github.io) 렌즈 자료 XML. 같은 이름의 내장 파일 대신 쓰고, 새 이름이면 더해서 씁니다. |

## 빌드

[Rust](https://rustup.rs)(stable)로:

```
cargo build --release
```

결과는 `target\release\Darkroom.exe`입니다.
